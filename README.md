# CHESyrian.github.io

Personal portfolio website for **Tarek Ghajary**, hosted with GitHub Pages.

**Live site:** https://chesyrian.github.io

## Enable GitHub Pages (one-time)

1. Open the repository → **Settings** → **Pages** (left sidebar).
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**.
3. Select branch **master** and folder **/ (root)**.
4. Click **Save**.

After a minute or two the site will be available at:
https://chesyrian.github.io

## Customize

Edit `index.html` to update your bio, projects, links, or design.
